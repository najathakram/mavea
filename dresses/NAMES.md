# Dress names — the first twenty

Named 2026-08-16 from the full-garment renders in `source/`.

**Convention:** `<given name> <fabric> <garment type>` — the pattern already set by
*Nayana Linen Abaya* in the design mockups. Fabric is named only where the render
actually shows it. Where it does not, the name is `<given name> <garment type>` and no
fabric is claimed.

**Register:** soft, ordinary Sri Lankan Muslim women's given names. `NAMING.md` lists
Noor, Zahra, Amara, Inaya, Layla, Hana and Farah as names already in use on dresses, so
those seven are held back here; these twenty follow their register without repeating them.
ASCII letters and spaces only — these become folder names and later URL slugs.

Both `dresses/<name>/` (component shots) and `dresses/source/<name>/` (full renders)
carry the identical name.

## Notes

- Eight of the twenty are matte black crepe. That is the collection, not a naming
  shortcut — the given name is what separates them.
- Nine garments carry a named fabric (satin ×3, crepe ×5 by weave, linen ×1). Three name
  no fabric at all, because the render does not settle it.
- *Nayana* is left unused. It appears in the mockups as *Nayana Linen Abaya*, and Dress 6
  is the only linen garment here but is a coat dress, not an abaya. Reusing the name would
  have made the mockup wrong rather than real.
